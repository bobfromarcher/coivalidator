# COI Validator Site

Recovered canonical source for the COI Validator static site.

## Development

Open `index.html` directly or serve this directory with any static server.

```bash
python3 -m http.server 3000
```

## Deploy

This site is static. Production DNS currently points `coivalidator.com` and `www.coivalidator.com` to `coivalidator.pages.dev` through Cloudflare.
